`continuous.mp4` is a two-second, 24 fps H.264 test clip rendered from Boogie's
bundled Sophia animation against a white background. It tests video decoding,
local background removal, full-frame playback, and persistence without AI access.
It contains no user photographs. The source character is licensed Renderpeople
artwork; see [the character credits](../../assets/CHARACTERS.md).

`avatar.json` is a recorded legacy Codex geometry response based on a synthetic
avatar, retained to check compatibility with previously saved toy dancers.
